LLMs for healthcare, and why they are not transparent

My section of AI in Healthcare: Disease Diagnoses, Autonomous Workflows and Consumer LLMs, a paper written with Ra’Kira Nelson, Cynthia Ma and Amy Chen. Only the part I wrote is reproduced here; references are renumbered for this excerpt.

Introduction

Large Language Models (LLMs) seem to be the dream for individual health: free, 24/7, personalized, and able to consider vast amounts of context. In this section, we will explain how these models work, with a focus on the attention mechanism which birthed ChatGPT and most modern LLMs [1]. By understanding how the LLM pipeline works, we can see how its very nature gives rise to ethical concerns once applied to healthcare.

How it works

Word vectors

Humans associate words with concepts, and LLMs do the same. But while humans read words as groups of letters, LLMs do not, because the letters in a word do not convey useful information about its meaning. Instead, every word is converted into a vector of numbers which represents its meaning [1]. Each element in the vector reveals how similar it is to a certain concept. For instance, the word "Louvre" would have large values for the concepts "museum" and "France" but low values on "beverages" and "astronomy". By having vectors in thousands of dimensions, a word’s relationship to thousands of concepts can be stored so that the word’s meaning is represented in a nuanced way. This leads to some notable properties. First, words that are similar in meaning, such as "cat" and "dog", tend to have vectors that are near each other. This makes sense, because they would both score high on dimensions such as "pet", "mammal", and "adorable". Second, these vectors often encode meanings such that adding and subtracting vectors can illustrate relationships between words. For instance, let us consider a toy example with a vector pattern that represents a word’s relationship to four concepts: "cardiovascular", "respiratory", "organ", and "resource". Attention

Consider a user typing into an LLM, "my chest hurts". While it is obvious to humans that the user is seeking relief from chest pain, a computer cannot determine this as easily, because some words have two meanings:

  • chest: body part ("my chest feels sore") or object ("my treasure chest")
  • hurts: physical ("the blister hurts") or emotional ("the breakup hurts")

Just like humans, any language model must look at surrounding words for context to distinguish which meaning the words have taken [1]. This inspires the concept of attention [2], which allows every word in a prompt to change the meaning of every other word. It does so by adjusting the word’s vectors to reflect the new meaning. Above, "hurts" would influence the "chest" vector to signify the body part, while "chest" would likewise influence the "hurts" vector to signify physical rather than emotional pain.

Neural network

After the initial matrix has been updated to include context from the attention process, it is passed as input into a feed-forward neural network with two layers [2]:

The neural network has two purposes. First, it allows the LLM to reference knowledge from external sources [1]. This can happen because texts such as books, newspapers, and websites were used to "train" the weights W₁, W₂, b₁, b₂ of the neural network. These weights "compress" the textual information from these sources into a compact numerical form. In our case, sources such as medical textbooks and journal articles would give an LLM medical knowledge, similar to what a doctor would have. Note that this is stored in the weights during training, and the LLM does not have real-time access to external sources afterwards.

Second, it allows the LLM to be more expressive. As seen above, attention transforms the values of the matrix X in a simple way, but often we want to model a more nuanced relationship between inputs and outputs. Adding a neural network with a nonlinear "activation function" such as ReLU(x) = max(0, x) lets the LLM approximate more complex functions. Indeed, it can now approximate any continuous function, according to a neat proof known as the Universal Approximation Theorem. This gives LLM the power to handle complex relationships in language and concepts.

The output of the neural network is a matrix of the same shape as the input, updated with context from external sources.

Layers

Attention enriches the context of the matrix X by looking at words within the input prompt, while the neural network injects context from external sources. So, combining them into a "layer" allows the LLM to consider both internal and external sources [1]. But we can go further and combine several layers into a stack, so the LLM alternates its updates using internal and external information [2]. It iteratively refines the context to be more and more accurate.

The output from the final layer is the matrix X of all words in the input prompt, with the full context from the prompt and external sources. All the context makes it so that each word becomes very predictive of the next word. This is due to how the neural network was trained: it learns to "guess" the word that follows a given context-enriched word.

So the last word of the sequence in the final layer is used to generate a new word. In our example, the word "hurts" would have all the context from "chest" and context from medical textbooks to predict the next word. Its vector gets converted into a probability distribution over all possible words, based on how likely it is to appear after. Then one word, such as the one with the greatest probability, is selected from this distribution. The LLM continues this process of selecting new words from a probability distribution until the response is complete.

Transparency

LLMs are not very transparent. First, the word vectors have a staggering size of thousands of dimensions [1]. To a human, they just look like long lists of meaningless numbers. Not only that, but these dimensions usually do not map to simple human concepts. While in our explanation we used dimensions such as "museum", "adorable", and "physical", the concepts used in word vectors may be so complex that they are not grounded in any human meaning [1].

Second, attention is not transparent. It uses an attention matrix filled with numbers that are learned during training [2]. These numbers can appear to be arbitrary and do not explain where they came from. Like the word vectors, it is hard to tell what is going on here.

Finally, the neural network is not transparent. Like attention, its weights and biases are learned during training [2]. Massive quantities of numbers are used to calculate the output every time an input is passed into a neural network in a way that is incomprehensible to any observer.

This means that the concerns about AI transparency discussed in this paper are very applicable to LLMs.

Hallucinations

As explained above, LLMs use a probability distribution to generate the next word. This means that their outputs are not verified to be reasonable or correct, but are just the result of repeated sampling from a distribution. As a result, advice and diagnoses which sound factual and well-considered can be misleading, incorrect, or harmful. This phenomenon emerges from the very nature of LLMs and is known as a hallucination. This is critical in the application to healthcare and raises concerns for misdiagnoses and liability that we discuss in the rest of this paper.
